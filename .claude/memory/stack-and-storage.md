Проект на Go. Хранилище — **embedded SQLite** в одном файле: метаданные + FTS5 (лексика) +
sqlite-vec (вектор). Ноль внешних сервисов на старте.

**Почему:** локальный агент, простота развёртывания, отсутствие тяжёлых зависимостей.
Postgres+pgvector — только если понадобится мультитенант/масштаб (не сейчас).
**Как применять:** весь SQL живёт в пакете `store/` за интерфейсом `Store`. vec-таблица
отдельная — вектор добавляется/переиндексируется без миграции `memories`.
