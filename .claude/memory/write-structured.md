При сохранении **структуру даёт агент**: передаёт готовый атомарный факт с полями
(`kind`, `content`, `importance`, `tags`, `scope`, опц. `links`). Система не извлекает факты
из сырого текста через LLM.

**Почему:** просто, дёшево, надёжно; меньше «магии» и точек отказа. Классификация на стороне
агента точнее и не стоит токенов.
**Как применять:** `write/` перед вставкой делает дедуп/обновление (лексика + SimHash по
content в том же scope), связывание (граф `links`), индексацию (FTS5 всегда; вектор — если
Embedder включён, иначе очередь на досчёт). Противоречащий факт → `superseded_by`, а не DELETE.

Связано: [[transport-mcp]]
