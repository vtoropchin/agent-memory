Семантический вектор — **локально через ollama**, дефолтная модель **bge-m3** (1024 dim,
мультиязычная: факты на русском, код на английском). Модель конфигурируема — можно указать
любую ollama-модель одной строкой.

**Почему:** приватность/оффлайн/без второго платного API; bge-m3 хорошо работает по русскому.
DeepSeek и Anthropic embeddings API НЕ предоставляют — только chat.
**Как применять:** `dim` не хардкодим — определяем пробным эмбеддингом при старте.
Смена модели → векторы несравнимы → сверяем `embed_meta`, при несовпадении пересоздаём
vec-таблицу и запускаем reindex (фоновый джоб); пока идёт — recall деградирует на FTS5.
ollama недоступен → recall на чистом FTS5, save откладывает вектор. Вектор — опциональный слой.
