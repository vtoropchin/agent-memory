# Задача 16.4 — Фронт: экран «Память» (`#/memory`): список, поиск, фильтры, состояния

**Статус:** ⬜ ожидает
**Этап:** 16 · **Область:** `cmd/memo/web/app.js`, `index.html`, `tailwind.input.css`.
**Зависимости:** 16.2 (каркас, роутер, scope).

## Что сделать (спецификация §2.2, §5, §6)

- Поиск: поле (`/` фокусирует), radiogroup «по смыслу | по словам»
  (`GET /api/search?q&mode&kind&scope`); без запроса — список
  `GET /api/memories?scope&kind&superseded=1&limit&offset` с пагинацией.
- Фильтр вида — пять чипов-чекбоксов (multiselect), «с архивом»; счётчик активных
  фильтров; **«Сбросить всё»** снимает вид, архив, запрос и scope. Всё — в хэше.
- Плашка деградации при `vector:false` в режиме «по смыслу» (текст §5).
- Строка результата: цветная кромка вида, вид + scope (+ стадия задачи),
  заголовок серифом (summary или content, 2 строки), теги, важность (5
  сегментов), когда, источник кандидата («по словам» / «слова + смысл»);
  архивная — зачёркнута, чип «в архиве · заменена»; подсветка совпадений
  запроса (только текст, без innerHTML с сырыми данными).
- Состояния: пусто в scope, нет результатов (разный текст при деградации),
  ошибка API с «Повторить» — тексты §5. `aria-live` на счётчике результатов.
- Клик по строке (кнопка внутри `article`) → панель записи (16.5); `id=` в хэше.
