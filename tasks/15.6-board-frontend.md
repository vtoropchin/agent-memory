## Контекст

Бэкенд доски готов (15.5). Нужен экран доски в той же одностраничной морде:
vanilla JS + Tailwind, бандл внутри бинаря, **без CDN и без сторонних JS-
библиотек** (решение пользователя из Этапа 6 — сохраняется; drag&drop — нативный
HTML5 DnD API). Стиль кода — как в `app.js` (`el()`/`clear()`, `api*()`,
состояние в `state`, обработчики без фреймворка).

Что должен уметь экран (по решениям DESIGN.md §14 Этап 15):

- 7 колонок в порядке стадий, заголовок колонки — русская метка + счётчик;
  `done` показывает `doneLimit` карточек и кнопку «показать ещё (N)».
- Карточка: тип-бейдж (`epic`/`story`; `task` без бейджа), заголовок
  (`summary`), звёзды importance, чипы tags, чип ветки (иконка/моно-шрифт),
  чип workflow, **красная плашка «ждёт: …»** с именами блокеров, у эпика/
  истории — прогресс-бар `done/total`; у карточки-ребёнка — короткая строка
  родителя. Клик — существующая модалка карточки записи.
- Drag&drop карточки между колонками → `PATCH {status}`; на 409
  (заблокирована) — карточка возвращается, тост с перечнем блокеров; на 400 —
  тост с текстом ошибки. Оптимистичное перемещение с откатом.
- Панель фильтров: scope (обязательный выбор проекта — селект из
  `stats.byScope`; дефолт — первый `project:*`), тип, ветка, workflow, тег,
  «только дети эпика/истории» (пикер), переключатель «группировать по эпику»
  (свимлейны: строка на эпик + строка «без эпика»; внутри — те же колонки).
- Навигация: переключатель «Память | Доска» в шапке, hash-роутинг
  (`#/board`, `#/` — список); выбранный scope и фильтры доски — в URL-хэше
  (`#/board?scope=…&type=…`), чтобы ссылка воспроизводила экран.
- Модалка карточки для `kind=task` — расширить: селект стадии, селект типа,
  поля `branch`/`workflow` (инлайн-редактирование по образцу tags), секция
  «Родитель» с пикером (поиск задач через `/api/search?mode=lexical&kind=task`,
  выбор → PATCH `links:[{id, rel:"part_of"}]`, снять → `unlinks`), секция
  «Заблокирована (ждёт)» — список с кнопкой снятия (`unlinks`) и пикером
  добавления (`links … rel:"blocked_by"`), секция «Блокирует» — read-only.
- Тёмная тема — как у остального (классы `dark:`).

## Что сделать

1. `index.html`: шапка с переключателем вида; контейнер `#board-view`
   (скрыт по умолчанию) рядом с существующим `#list-view` (обернуть текущие
   секции); разметка панели фильтров доски и сетки колонок — генерируется JS.
2. `app.js`:
   - роутер по `location.hash` (`hashchange`), состояние `state.view`,
     `state.board` (scope, фильтры, doneLimit, groupByEpic);
   - `loadBoard()` → `GET /api/board` с query из состояния; `renderBoard(board)`
     — колонки/свимлейны/карточки (`renderBoardCard`); константы меток
     стадий/типов — расширить `STATUS_LABEL`, добавить `TYPE_LABEL`;
   - DnD: `draggable`, `dragstart` (id), колонка — `dragover`/`drop` → PATCH;
     визуальная подсветка целевой колонки;
   - «показать ещё» — повторный запрос с `doneLimit *= 2` (или `+30`);
   - расширение `renderCardModal` для задач (см. выше), переиспользуя
     `apiPatch` и паттерн `renderTagsControl`; после успешного PATCH —
     перерисовать модалку и, если открыта доска, обновить карточку;
   - тосты ошибок — простой компонент (нет сейчас — добавить один общий).
3. `tailwind.input.css`: при необходимости — утилиты для колонок
   (горизонтальный скролл сетки на узких экранах); `make web-css`.
4. Проверить, что список «Память» и поиск не регрессировали (общие функции
   не ломать; новые — рядом).
