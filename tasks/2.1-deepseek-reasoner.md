# Задача 2.1 — DeepSeek-клиент Reasoner

**Статус:** ✅ выполнена (2026-07-11). Билд чист, 7 тестов зелёные, только stdlib.
**Этап:** 2 (Reasoner) · **Пакет:** `internal/memory/reason` · **Зависимости:** нет

## Контекст

В `internal/memory/reason/reason.go` есть интерфейс
`Reasoner { Complete(ctx, prompt string) (string, error) }` и заглушка `Noop`.
Нужна реализация поверх DeepSeek chat — OpenAI-совместимый API (DESIGN.md §6, §10, §13).

## Что сделать

1. Новый файл `internal/memory/reason/deepseek.go`:
   - Тип `DeepSeek`: httpClient (`*http.Client`, таймаут 60s по умолчанию),
     baseURL (дефолт `https://api.deepseek.com`), model, apiKey.
   - Конструктор `NewDeepSeek(apiKey, model string, opts ...Option)` — ключ передаёт
     вызывающий (env читает `cmd/memo`, НЕ этот пакет). Пустой apiKey/model → ошибка
     (fail fast). Опции: `WithBaseURL(string)` (для httptest), `WithHTTPClient(*http.Client)`.
   - `Complete(ctx, prompt)`: POST `{baseURL}/chat/completions`, JSON
     `{"model":…,"messages":[{"role":"user","content":prompt}],"temperature":0.3,"stream":false}`,
     заголовок `Authorization: Bearer <key>`. Вернуть `choices[0].message.content`.
     Пустой `choices` или не-2xx → ошибка с телом ответа (обрезать до ~1KB).
     Контекст пробрасывать через `http.NewRequestWithContext`.
   - `var _ Reasoner = (*DeepSeek)(nil)`.
2. Тесты `deepseek_test.go` через `httptest.Server`: успех (путь/метод/заголовок/тело),
   не-2xx, пустые choices, отмена контекста, пустой apiKey/model, `WithHTTPClient`.
   Никаких живых сетевых вызовов.
