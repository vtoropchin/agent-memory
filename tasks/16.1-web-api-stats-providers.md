# Задача 16.1 — API новой морды: `providers`/`jobs` в stats, `expiresBefore`, правка `content`/`summary`

**Статус:** ✅ выполнена (2026-09-22), см. «Результат» внизу
**Этап:** 16 (Новая веб-морда, DESIGN.md §14 Этап 16) · **Область:**
`internal/memory/store` (порт + оба драйвера), `internal/memory/maint/scheduler.go`,
`cmd/memo/main.go` (сборка планировщика), `cmd/memo/web.go`, `cmd/memo/web_test.go`,
DESIGN.md §4/§6/§12.
**Зависимости:** нет; выполняется первой — фронт 16.3/16.5 опирается на её контракт.

## Контекст

Спецификация `design/memo-web-redesign.md` §7 перечисляет, чего не хватает
API для новой морды. Решения приняты (DESIGN §14 Этап 16):

1. `GET /api/stats` расширяется полями `providers` и `jobs`.
2. `GET /api/memories` получает фильтр `expiresBefore`.
3. `PATCH /api/memories/{id}` принимает `content`/`summary` — инвариант §12
   снят; `Writer` морды собирается с реальным Embedder.

## Что сделать

1. **Порт `store.Store`** (`store.go`, обе реализации `sqlite.go` /
   `postgres*.go`, паритет):
   - `Stats.PendingVectors int` — `COUNT` живых записей без строки в векторном
     индексе (`LEFT JOIN … IS NULL`, как в `ListMissingVectors`); нет индекса
     → 0 без ошибки.
   - `SchemaVersion(ctx) (int, error)` — SQLite `PRAGMA user_version`,
     PostgreSQL `SELECT version FROM schema_version` (0, если строки нет).
   - `LastMaintRun(ctx) (int64, error)` / `SetLastMaintRun(ctx, at int64) error`
     — таблица `maint_meta(id=1, last_run_at)` в базовой схеме обоих драйверов
     (`CREATE TABLE IF NOT EXISTS`, по образцу `embed_meta`; без шага миграции).
     Чтение при отсутствии строки — `0, nil`.
   - `BrowseFilter.ExpiresBefore int64` — при `> 0` добавляет
     `expires_at IS NOT NULL AND expires_at > 0 AND expires_at < ?` и меняет
     сортировку на `expires_at ASC`.
   - Тесты store: `store_test.go`/`expiry_test.go` (sqlite) и `postgres_test.go`
     (под `MEMO_TEST_POSTGRES_DSN`) на каждый пункт.
2. **`maint.Scheduler`**: узкий порт-потребитель `RunLog { SetLastMaintRun }`
   и поле `now func() int64` (время — полем, не `time.Now()` в теле, CLAUDE.md);
   `RunOnce` в конце пишет отметку, ошибка записи — лог, не падение.
   `NewScheduler` получает порт параметром; `cmd/memo/main.go` передаёт `s`.
   Тест: после `RunOnce` отметка записана; ошибка записи не роняет прогон.
3. **`cmd/memo/web.go`**:
   - `runWeb`: `write.New(s, embedder)` вместо `embed.NewNoop()`; сборка
     описания инстанса (`webInstance`: homeScope, драйвер/target хранилища,
     provider/model эмбеддера и reasoner'а, доступность reasoner'а через
     `newReasoner` → не `*reason.Noop`).
   - `handleStats`: `providers:{store:{driver,target,schema}, embedder:{provider,
     model,dim,available,pending}, reasoner:{provider,model,available}}`,
     `jobs:{lastRunAt}` (`null`, если 0). `available` эмбеддера — `Dim() > 0`.
   - `handleListMemories`: параметр `expiresBefore` (unix, целое ≥ 0; мусор → 400).
   - `handlePatchMemory`: поля `content`/`summary` → `UpdateInput.Content/Summary`;
     `patchMemoryAllowedFields` дополнить; `ErrEmptyContent` уже маппится в 400.
   - Комментарий пакета и годоки `runWeb`/`newWebHandler` — под новый инвариант.
   - `web_test.go`: stats отдаёт providers/jobs (noop-эмбеддер → `available:false`,
     `pending` считает записи без вектора при созданном индексе; `lastRunAt`
     после `SetLastMaintRun`); `expiresBefore` фильтрует и сортирует;
     PATCH `content`/`summary` меняет запись, пустой `content` → 400, `summary:""`
     снимает заголовок.
4. **DESIGN.md**: §4 — таблица `maint_meta`; §6 — новые методы Store; §12 —
   абзац web-морды: инвариант «content/summary из браузера не редактируются»
   заменить на новый (см. §14 Этап 16), контракт `/api/stats` и `expiresBefore`.

## Границы

- Фронт (`cmd/memo/web/*`) не трогать — это 16.2+.
- `internal/memory/write`/`recall`/`board` не менять: `UpdateInput.Content/Summary`
  уже есть, переэмбеддинг делает `Writer.Update`.
- Базовая линия `TestDependencyRule` не растёт (maint уже импортирует store;
  порт планировщика — интерфейс потребителя).
- Динамический health-пинг провайдеров — нет (отложено, §14 Этап 16).

## Проверка

- `make build`, `make test` зелёные; PostgreSQL-тесты store — при доступном
  `MEMO_TEST_POSTGRES_DSN`.
- `bin/memo web` на живой базе: `curl /api/stats` показывает providers/jobs
  (после прогона MCP-сервера `lastRunAt` не null); `curl '/api/memories?expiresBefore=…'`;
  `curl -X PATCH … -d '{"content":"…"}'` → 200 и новый текст в `GET`.

## Результат (2026-09-22)

**Сделано (факты):**

  драйвера — своя проверка индекса), `BrowseFilter.ExpiresBefore` (фильтр +
  сортировка `expires_at ASC, id ASC` в обоих `List`), `SchemaVersion` (SQLite
  `PRAGMA user_version`, PG `schema_version`), `LastMaintRun`/`SetLastMaintRun`
  (таблица `maint_meta` в базовой схеме sqlite/postgres, общий
  `lastMaintRunFromDB`, upsert в каждом драйвере). Тесты —
  `store/instance_meta_test.go` (паритетные + точная версия SQLite).
- `maint.Scheduler`: порт `RunLog { SetLastMaintRun }` (объявлен потребителем),
  поле `now func() int64`, отметка в конце `RunOnce` (ошибка — лог);
  `NewScheduler(…, runLog, interval, consolidateAfter)`; `cmd/memo/main.go`
  передаёт store. Тесты `TestSchedulerRunOnceRecordsLastRun`,
  `TestSchedulerRunOnceRunLogErrorDoesNotPanic`.
- `cmd/memo/web.go`: `webInstance`/`newWebInstance(cfg, reasonerAvailable)`;
  `newWebHandler(s, w, rc, embedder, inst)`; `/api/stats` → `providers`
