# Задача 16.6 — Фронт: экран «Доска» (`#/board`) и панель задачи

**Статус:** ⬜ ожидает
**Этап:** 16 · **Область:** `cmd/memo/web/app.js`, `index.html`, `tailwind.input.css`.
**Зависимости:** 16.2 (каркас), 16.5 (общая панель записи).

## Что сделать (спецификация §2.4, §2.5, §5, §6)

- Панель доски: тип · «Внутри» (пикер эпика/истории через
  `GET /api/search?q&mode=lexical&kind=task`) · тег · «дорожки по родителю»
  (вкл. по умолчанию) · счётчик задач и заблокированных · «Сбросить». Всё — в
  хэше (`type`, `parent`, `tag`, `group`, `doneLimit`); scope — глобальный.
- Подсказка одной строкой (перетащить / открыть и сменить стадию / Enter →
  поле «Стадия»).
- Семь колонок (`GET /api/board`), `done` — `doneLimit` + «показать ещё»
  (удвоение). Свимлейны — группировка по `parent` на клиенте.
- Карточка: тип · «заблокирована» (красным, `title` с блокерами) · важность ·
  заголовок-кнопка · прогресс `done/total` · ветка (mono) · когда ·
  `select` «Переместить в стадию» (виден при hover/focus) → `PATCH {status}`.
  Стили типов и штриховка заблокированной — §2.4.
- DnD: нативный HTML5, подсветка целевой колонки, оптимистичный перенос;
  409 `{error, blockers}` → откат + тост «Не переведена: «…» заблокирована —
  <блокеры>»; 400 → откат + тост с текстом.
- Панель задачи (поверх 16.5): заголовок, плашка «Заблокирована…», поля 2×2
  Стадия · Тип · Ветка · Процесс (каждое → PATCH сразу, откат на ошибку),
  приоритет, описание, **Входит в** (родитель + «Отвязать» `unlinks part_of` +
  пикер `links part_of`), **Дочерние** (прогресс + список), **Блокировки**
  (ждёт: «Снять» `unlinks blocked_by`; блокирует; пикер «Добавить блокер»),
  Связано, Теги, Служебное. После PATCH, меняющего вычисляемое, —
  перечитать карточку и обновить доску.

## Границы

Правило блокировки, направление `part_of`, усечение `done` — бэкенд (`board`,
`write`); фронт рисует ответ и маппит ошибки.

## Проверка

`make build`/`make test`, `node --check`; в браузере — сценарий 4 §9 (стадии,
карточка, блокировки, part_of; перенос мышью и с клавиатуры), 409 → откат +
тост, свимлейны, «показать ещё», ширина ~1024 px.

## Критерий приёмки

Сценарий 4 §9 проходит на живой базе; DnD дублируется `select` и полем «Стадия».
