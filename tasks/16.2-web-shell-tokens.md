# Задача 16.2 — Фронт: каркас новой морды, токены, роутер, панель записи, тосты

**Статус:** ⬜ ожидает
**Этап:** 16 (DESIGN.md §14 Этап 16) · **Область:** `cmd/memo/web/index.html`,
`cmd/memo/web/app.js`, `cmd/memo/tailwind.input.css` (+ `make web-css` →
`cmd/memo/web/tailwind.css`), при необходимости `cmd/memo/web_test.go` (статика).
**Зависимости:** 16.1 (контракт `/api/stats` для селекта scope и шапки).

## Контекст

Спецификация — `design/memo-web-redesign.md` (§2 экраны, §3 токены, §4
доступность, §5 тексты); макет — `design/memo-web-prototype.html` (`:root`,
классы `.panel`, `.drawer`, `.toast`, HTML-комментарий в конце файла). Старый
`index.html`/`app.js` **переписываются под новую структуру, не дописываются**
(§8 спецификации); стек прежний: vanilla JS + Tailwind, без CDN и сторонних JS.

## Что сделать

1. `tailwind.input.css`: токены из `:root` макета как есть (поверхности, текст,
   линии, акцент, цвета видов, тёмная тема под `prefers-color-scheme: dark`),
   шрифты (интерфейс — системный sans; содержание памяти — сериф; id/ветки —
   mono), `:focus-visible` кольцо, важность как 5 сегментов, компонентные классы
   макета, которые не выражаются утилитами. `make web-css`.
2. `index.html`: skip link, `<header>` с `<h1>`, три раздела (`#/`, `#/memory`,
   `#/board`, `aria-current`), справа — единственный селект scope
   (`все scope` + `stats.byScope`, домашний помечен по `homeScope`); контейнеры
   трёх экранов (пустые — наполняются задачами 16.3–16.6); контейнер панели
   записи; контейнер тостов (`aria-live=polite`).
3. `app.js`: состояние в URL-хэше — раздел, `scope`, фильтры, `id=` открытой
   записи (`parseRoute`/`navigate`, `hashchange`); `api()` c ошибками
   `{status, body}`; общий селект scope → перерисовка текущего экрана; панель
   записи: ≥ 1200 px — по центру (720 px), уже — у правого края; `role=dialog
   aria-modal`, `inert` на фоне, Esc закрывает, фокус возвращается на открывший
   элемент; тосты (`showToast`) по текстам §5. Каркас экранов — заглушки с
   заголовком, чтобы роутер и scope работали end-to-end.
4. Относительные даты («2 ч назад», старше 30 дней — дата без времени) — один
   хелпер `rel()`, как в макете.

## Границы

- Бэкенд не трогать; экраны наполняются следующими задачами.
- Доменной логики нет; никаких сторонних библиотек.

## Проверка

- `make build`, `make test` (статика встраивается `embed.FS`; `TestStaticIndexServed`
  зелёный), `node --check cmd/memo/web/app.js`.
- В браузере: три раздела переключаются по хэшу, scope сохраняется в хэше,
  панель открывается/закрывается с клавиатуры, тёмная тема применяется.

## Критерий приёмки

Каркас работает поверх живого `bin/memo web`; токены и шрифты совпадают с
макетом; чек-лист §4 спецификации для шапки/панели/тостов пройден.
