**Статус:** ✅ выполнена (2026-09-22). Факты: `make build`, `make test` (12 пакетов,
`TestStaticIndexServed` зелёный), `make web-css` (Tailwind v4.3.2 standalone, 17,7 КБ),
`node --check cmd/memo/web/app.js`. Ручная проверка во встроенном браузере на живом
`bin/memo web -config . -addr 127.0.0.1:7071` (PostgreSQL, 7 scope): три раздела
переключаются по хэшу с `aria-current`, ссылки разделов несут текущий scope; при пустом
стартовом хэше подставляется домашний `project:AgentMemory` (`location.replace`,
`#/?scope=…`), селект помечает его «(домашний)», смена scope пишет хэш и перерисовывает
заглушку; панель по `id=` в хэше — `role=dialog aria-modal`, фокус на диалог, `inert` на
шапке/main/skip link, Esc и «Закрыть» закрывают с возвратом фокуса на открывший элемент;
на 1300 px панель по центру 720 px со скруглением и тенью, на 375 px — во всю ширину;
тёмная (`#15171B`) и светлая (`#F5F5F2`) темы по `prefers-color-scheme`; шрифты: UI —
`-apple-system…`, summary/content — `Iowan Old Style…`; skip link переводит фокус в
`main`, не трогая хэш; тост `role=status` в `aria-live=polite`; 404 записи и отказ
`/api/stats` дают плашки §5 с «Повторить». Не проверено инструментом: активация
кнопки «Закрыть» клавишей Enter — встроенный браузер не эмитит `keypress`, на которой
Chrome активирует `<button>` (Enter на ссылке разделов и Esc сработали); поведение
стандартное для `<button type=button>`.

## Что сделать

1. `tailwind.input.css`: токены из `:root` макета как есть (поверхности, текст,
   линии, акцент, цвета видов, тёмная тема под `prefers-color-scheme: dark`),
   шрифты (интерфейс — системный sans; содержание памяти — сериф; id/ветки —
   mono), `:focus-visible` кольцо, важность как 5 сегментов, компонентные классы
   макета, которые не выражаются утилитами. `make web-css`.
2. `index.html`: skip link, `<header>` с `<h1>`, три раздела (`#/`, `#/memory`,
   `#/board`, `aria-current`), справа — единственный селект scope
   (`все scope` + `stats.byScope`, домашний помечен по `homeScope`); контейнеры
   трёх экранов (пустые — наполняются задачами 16.3–16.6); контейнер панели
   записи; контейнер тостов (`aria-live=polite`).
3. `app.js`: состояние в URL-хэше — раздел, `scope`, фильтры, `id=` открытой
   записи (`parseRoute`/`navigate`, `hashchange`); `api()` c ошибками
   `{status, body}`; общий селект scope → перерисовка текущего экрана; панель
   записи: ≥ 1200 px — по центру (720 px), уже — у правого края; `role=dialog
   aria-modal`, `inert` на фоне, Esc закрывает, фокус возвращается на открывший
   элемент; тосты (`showToast`) по текстам §5. Каркас экранов — заглушки с
   заголовком, чтобы роутер и scope работали end-to-end.
4. Относительные даты («2 ч назад», старше 30 дней — дата без времени) — один
   хелпер `rel()`, как в макете.
