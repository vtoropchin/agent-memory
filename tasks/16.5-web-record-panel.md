# Задача 16.5 — Фронт: панель записи — просмотр, связи, правка, «Забыть»

**Статус:** ⬜ ожидает
**Этап:** 16 · **Область:** `cmd/memo/web/app.js`, `index.html`, `tailwind.input.css`.
**Зависимости:** 16.1 (PATCH `content`/`summary`), 16.2 (каркас панели), 16.4 (открытие из списка).

## Что сделать (спецификация §2.3, §5, §6)

- `GET /api/memories/{id}` → шапка (вид · scope · «Закрыть»; для задачи —
  «К доске»), важность (кликабельные сегменты → `PATCH {importance}`),
  «создана», summary (сериф, крупнее), полный текст (сериф, `pre-wrap`).
- **Теги**: чипы с ×, поле «+ тег…» (Enter → `PATCH {tags}` заменяющей семантикой),
  тосты «Тег «x» добавлен/снят».
- **Связи**: исходящие (`links` записи) и входящие (из `neighbors`: у кого
  `dst == id`) с подписями по `rel` из §2.3; у цели — вид и заголовок; клик
  открывает её в той же панели (история — `id=` в хэше).
- **Похожие по вектору**: `semanticNeighbors` с расстоянием; при
  `embedding.embedded == false` — «нет данных — эмбеддер недоступен / в очереди».
- **Служебное**: id, полные даты, «читалась N раз», источник, вектор/в очереди.
- Архивная (`supersededBy != null`): плашка «В архиве с … — заменена записью <…>»,
  без правки. TTL (`expiresAt`): плашка «Истекает через …».
- Футер: **Изменить** → инлайн-правка summary/текста → Сохранить (`PATCH
  {content, summary}`) / Отменить, тост «Сохранено»; **Забыть…** → инлайн-
  подтверждение §5 (число связей; для задачи с детьми — «K дочерних задач
  останутся без родителя», из `children`) → `DELETE` → тост, закрытие панели,
  обновление списка.
- Ошибки PATCH/DELETE (400/404/409/сеть) → тост с текстом сервера.
