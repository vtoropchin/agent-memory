## Что сделать (спецификация §2.1, §5, §6, §7)

- Заголовок: `N записей в <scope>` · `M в архиве` · `обновлено <относительно>`
  (`GET /api/stats`, `homeScope`).
- Плашка деградации по `providers.embedder.available == false` (текст §5 «Поиск по
  смыслу недоступен…» с provider/model из ответа).
- Пять счётчиков по видам (`byKind`; клик → `#/memory?kind=…`).
- «Добавлено за 7 дней» — `GET /api/memories?scope&limit=10`, отсечь по
  `createdAt` на клиенте; пусто → текст-приглашение §5.
- «На доске» — `GET /api/board?scope`, на клиенте: `doing`, затем
  `review`/`testing`, затем заблокированные (`blocked`); вторая строка
  «заблокирована · ждёт: <блокер>»; клик → панель задачи (16.5/16.6).
- Правая колонка: **Сервисы** (хранилище — driver/target/схема; эмбеддер —
  provider/model/dim, точка ok/off, «очередь на эмбеддинг пуста» / «N записей
  ждут эмбеддинга»; reasoner — provider/model, ok/off; фоновые джобы —
  `jobs.lastRunAt` относительно, `null` → «ещё не запускались»), **Истекает
  скоро** (`GET /api/memories?scope&expiresBefore=now+14d&limit=10`; нет
  записей — секцию не показывать), **Scope** (`byScope`, клик → выбрать scope).
- Списки: колонка меток 96 px, даты справа (§2.1).
