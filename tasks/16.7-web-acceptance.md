(`cmd/memo/web/*`, при необходимости `web.go`).
**Зависимости:** 16.1–16.6.

## Что сделать

1. Собрать `make bin/memo`, запустить `bin/memo web` на **PostgreSQL** (конфиг
   инстанса) и на **SQLite** (копия: `memo export` → `memo import -db …`).
2. Пройти пять сценариев §9 `design/memo-web-redesign.md` на обеих базах;
   зафиксировать факты по каждому пункту (что нажато, что показано, какие
   запросы ушли — вкладка сети).
3. Чек-лист §4: контраст ≥ 4.5:1 текста и ≥ 3:1 границ в светлой и тёмной
   теме (по токенам §3; выборочно — измерить), `:focus-visible` на всём
   интерактивном, панель (`role=dialog`, `inert`, Esc, возврат фокуса), DnD
   дублирован `select`/полем «Стадия», skip link, `<h1>`, `aria-live` только
   на тостах и счётчике.
4. Деградация: `embedder.provider="noop"` → плашки на обзоре и в памяти,
   «нет данных» в похожих; остановленный `memo web` → экран ошибки API с
   «Повторить».
5. Дефекты — чинить в этой задаче, если они локальны (фронт/маппинг ошибок);
   иначе — заводить задачу и описать.
