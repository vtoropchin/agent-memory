# Задача 2.4 — Связка Reasoner в memo и конфиге

**Статус:** ✅ выполнена (2026-07-11) — `newReasoner` в `cmd/memo/main.go` создаёт
Reasoner по `cfg.Reasoner.Provider` (noop/deepseek/неизвестный→ошибка), деградация на
Noop при пустом `DEEPSEEK_API_KEY`; добавлен `config.example.toml`; табличный тест
`TestNewReasoner` в `cmd/memo/main_test.go`. Билд и тесты зелёные
(`CGO_ENABLED=1 go build/test -tags sqlite_fts5 ./...`).
**Этап:** 2 (Reasoner) · **Пакеты:** `cmd/memo`, `internal/config`
**Зависимости:** 2.1 (DeepSeek-клиент), 2.2 (recall принимает Reasoner), 2.3 (maint.Consolidator)

## Контекст

После 2.1–2.3 в коде есть `reason.DeepSeek`, `recall.New(..., reasoner)` и
`maint.NewConsolidator(...)`, но `cmd/memo` всё ещё создаёт `reason.NewNoop()`.
DESIGN.md §10: ключ — `DEEPSEEK_API_KEY` (env). §13: `[reasoner] provider = "deepseek"`.

## Что сделать

1. `cmd/memo/main.go`: фабрика Reasoner по конфигу:
   - `provider == "noop"` (дефолт) → `reason.NewNoop()`.
   - `provider == "deepseek"` → ключ из env `DEEPSEEK_API_KEY`; пустой ключ →
     предупреждение в stderr и откат на Noop (деградация §15, сервер стартует);
     иначе `reason.NewDeepSeek(key, cfg.Reasoner.Model)`.
   - Неизвестный provider → ошибка при старте (fail fast: это опечатка в конфиге).
   Полученный Reasoner передать в `recall.New(...)`.
2. Проверить, что `config.Default()` соответствует §13 (`provider="noop"`,
   `model="deepseek-chat"`) — менять дефолт НЕ нужно (включение DeepSeek — решение
   пользователя в конфиге).
3. Добавить в корень репо `config.example.toml` с полным примером конфига по §13
   и комментариями (какие провайдеры бывают, откуда берётся ключ).
4. Тест не обязателен для фабрики в main (тонкая обёртка), но если выделяешь фабрику
   в функцию — покрой её табличным тестом (noop / deepseek без ключа / deepseek с ключом /
   неизвестный).

## Границы

Не трогать пакеты `reason`, `recall`, `maint`, `mcp`, `store`, `write` — только связка.
Consolidator в memo пока НЕ инстанцировать (запуск по расписанию — Этап 4, задача 4.3).

## Критерий приёмки

- Билд чист; `CGO_ENABLED=1 go test -tags sqlite_fts5 -count=1 ./...` зелёный.
- `provider="noop"`: сервер стартует, recall работает как раньше.
- `provider="deepseek"` без ключа: предупреждение, сервер работает на Noop.
