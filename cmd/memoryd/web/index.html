AgentMemory — web-морда (read-only viewer)

Фронтенд ещё не реализован — это заглушка задачи 6.2 (HTTP-сервер + JSON API). Сам интерфейс просмотра памяти появится в задаче 6.3.

Пока можно проверить API напрямую:

  • /api/stats — сводные счётчики памяти
  • /api/memories — постраничный список (query: scope, kind, superseded, limit, offset)
  • /api/memories/{id} — карточка записи + соседи по графу связей
  • /api/search?q=... — лексический поиск (FTS5)
