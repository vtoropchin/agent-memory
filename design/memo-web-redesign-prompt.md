/dev Реализуй Этап 16 — новую веб-морду `memo web` по принятому дизайну.

## Источники истины
- `design/memo-web-redesign.md` — спецификация: экраны, поведение, токены, тексты,
  доступность, критерий приёмки. Первична.
- `design/memo-web-prototype.html` — принятый макет (открой в браузере, пройди пять
  сценариев из §9 спецификации, посмотри панель «Состояния макета» внизу слева и
  HTML-комментарий в конце файла с заметками для реализации). Иллюстрирует спецификацию.
- `DESIGN.md` §4, §12 (web-морда, доска), §14 Этап 15 — текущий контракт API и инварианты.
- `memory_recall` по scope `project:AgentMemory` — запись о принятии макета и решения Этапа 15.

## Что сделать (порядок важен — сначала бэкенд, потом фронт)

1. **Спланировать Этап 16 в DESIGN.md §14** и нарезать `tasks/16.x-*.md` по конвенции
   проекта (`tasks/README.md`, образец — `tasks/15.6-board-frontend.md`). Каждую задачу —
   отдельной сессией, эта сессия делает планирование и задачу 16.1.
2. **16.1 — API:** (а) `GET /api/stats` → поля `providers` и `jobs` (спецификация §7.1;
   провайдеров знает composition root `cmd/memo`, очередь эмбеддинга —
   `Store.ListMissingVectors`/count); (б) `expiresBefore` в `GET /api/memories`;
   (в) `PATCH /api/memories/{id}` принимает `content`/`summary` → `write.UpdateInput`
   — это снятие инварианта DESIGN §12 «content/summary из браузера не редактируются»;
   **на этапе design остановись и подтверди у меня это отклонение** до кода, затем
   поправь DESIGN §12 в той же задаче. Тесты `web_test.go` на новые поля.
3. **16.2 — фронт, каркас и токены:** токены из `:root` макета → `tailwind.input.css`
   (`make web-css`), шапка с тремя разделами и глобальным scope, hash-роутер
   `#/`, `#/memory`, `#/board` (+ `id=` открытой записи), панель записи (центр/справа,
   `inert`, Esc, возврат фокуса), тосты. Старый `index.html`/`app.js` переписываются под
   новую структуру, не дописываются.
4. **16.3 — Обзор**, **16.4 — Память (список, поиск, фильтры, состояния)**,
   **16.5 — Запись (просмотр, связи, правка, забыть)**, **16.6 — Доска и задача**
   (DnD + `select` «Переместить» + поле «Стадия»; 409 → откат + тост).
5. **16.7 — ручной чек-лист** по §9 спецификации на SQLite и PostgreSQL, тёмная тема,
   клавиатура, контраст (§4).

## Границы
- Стек не меняется: vanilla JS + Tailwind, бандл в бинаре, без CDN и сторонних JS.
- Доменной логики на фронте нет; PATCH остаётся whitelist-DTO 1:1 в `write.UpdateInput`;
  `kind`/`scope`/создание записей/hard DELETE из браузера — по-прежнему нет.
- Ядро (`internal/memory/*`) и драйверы `store` не трогать сверх нужного для 16.1
  (count очереди эмбеддинга, фильтр `expiresBefore`); базовая линия `TestDependencyRule`
  не растёт.
- Тексты интерфейса — из §5 спецификации, на русском; комментарии в коде — на русском.
- Не выходить за рамки: без «заодно», без абстракций на будущее.
